### P3（观察）
- **P3-1 [理论边界]** `aggregate` 缓存率：`total_cached > 0` 而 `total_input == 0` 时输出 `"NaN%"`（stats.rs:331-335）。现实中 input ≥ cached 通常成立，概率极低；建议防御性回退 `"-"`。
- **P3-2 [范围外行为]** OpenAI 兼容路径的**非流式**请求（stream=false）usage 不会被记录：tee 只解析 SSE 帧，非 SSE body 返回 None。spec 仅要求转换路径的非流式提取，不构成违规，但 README "every proxied request … token counts" 的措辞略宽于实际。
- **P3-3 [记录偏差]** issue 07 记录 usage.rs "12 个测试"，实际 14 个（aafd243 提交说明亦写 12）。
- **P3-4 [展示细节]** WebUI byProvider 旧数据行（无 token 字段）Tok 列显示 "0" 而非 "-"；与无数据惯例（`-`）不一致，但测试明确接受该行为，不影响正确性。
